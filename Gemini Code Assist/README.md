# Gemini Code Assist

**Type:** IDE Extension + CLI + Cloud
**Developer:** Google
**Status:** Active (Production)
**Last Updated:** April 2026

## Overview

Gemini Code Assist (formerly Google Duet AI) is Google's AI coding assistant, tightly integrated with Google Cloud, Firebase, and Android Studio. It offers one of the most generous free tiers in the market with 180,000 code completions per month and a 1M token context window.

## Models Supported

| Model | Use Case |
|-------|----------|
| Gemini 2.5 Pro | Primary model for code generation and chat |
| Gemini 3 | Next-gen model with "Finish Changes" feature |

## Key Features (2026)

- **Agent Mode with Auto Approve**: Multi-file autonomous operations with optional auto-execution
- **Inline Diff Views**: Line or block-level review of AI suggestions
- **Checkpoints and Rollbacks**: One-click revert to previous project state
- **Context Drawer**: Precisely control which files/folders the agent sees
- **Custom Commands**: Save and reuse prompt templates for team workflows
- **Finish Changes**: Converts TODOs and pseudocode into completed implementation
- **File Outline**: Navigate and instruct about file structure and intent
- **1M Token Context Window**: One of the largest context windows available
- **Source Citation**: Shows code sources with copyright indemnification
- **Free Tier**: 180,000 completions/month, 240 daily chat sessions
